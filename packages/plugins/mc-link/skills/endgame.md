# 通关参考（不是常驻提示）

> 来自 dsh-mc-agent 的长期主线，简化成参考；只在 `mcb_help endgame` 时读，不自动注入。

## 阶段

1. **石器**：木 → 工作台 → 木镐 → 石镐/石剑/熔炉。
2. **铁器**：铁镐/铁剑/盾；铁甲可不做。
3. **钻石工具**：钻石镐。
4. **造家**：床 + 分类箱子 + 工作台 + 熔炉 + 围栏 + 火把 + 小麦田。
5. **钻套**：钻石剑 + 全套护甲。
6. **下界**：钻套齐 → 黑曜石/打火石/弓/箭/金锭 → 下界。
7. **末地**：12 末影之眼 + 弓/箭 + 床 + 满状态。
8. **打龙**：龙血归零。

## 原则

- 活着优先；血/氧/岩浆/坠落第一。
- 先查背包再采/合成，别重复劳动。
- 做一小步就核验返回，别把“动作发出”当成功。
- 卡住先 `mcb_scan/mcb_map`，手动脱困。
- 天黑/低血/背包满/离家远，先回家。
- 不要为了阶段达标硬赌。
