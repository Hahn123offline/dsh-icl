# B 站工具整合

> 2026-11-03。工具链：搜索 → 看信息/字幕 → **看画面** → 读评论 → 记笔记。
> 所有工具只读；没有发评论/发动态的入口。

## 工具

| 工具 | 做什么 |
|---|---|
| `bili_search` | 搜索视频（标题/UP/播放量/时长） |
| `bili_watch` | 视频详情 + 字幕（有字幕才返回） |
| `bili_frames` | **切关键帧宫格 + 时间轴**，并让视觉模型描述每一格 |
| `bili_comments` | 高赞评论 + 每条的前几条楼中楼回复（只读） |

## 看画面是怎么做的

`bili_frames` 调 `dsh-video-storyboard` 的 CLI 生成宫格图，然后把图**发给视觉模型**，
把逐格描述拼回工具结果：

```
已切好宫格图：.../sheet.png
#1 0s–65s / #2 65s–131s / #3 131s–194s / #4 194s–259s

画面描述：
格子1：远景，天空中悬着一艘银白色飞行器，下方是密集的摩天楼与人群……
格子2：室内用餐场景，长桌旁多人吃饭……
```

**这样即使会话端只支持文本工具，也能"看到"画面**，而不是只读简介。

配置（插件 config 或环境变量）：

```
vision.baseUrl   默认 http://127.0.0.1:8088/v1
vision.model     默认 coder390-27b-q3-df2-4x325（本地视觉模型）
ICL_VISION_BASE / ICL_VISION_MODEL 可覆盖
visionEnabled: false 可关掉描述（只返回宫格路径）
```

实测（BV1MfsxzKEE6，4 格）：拿到了详细画面描述，包括飞船、楼群、人群、餐桌场景。

## 评论

`bili_comments` 返回高赞评论以及每条评论的 `top_replies`（前几条回复），
能覆盖"楼中楼"的浅层。**没有完整展开整楼**的能力（外部 MCP 只提供到这个深度）。

## 与 DSH 原生 storyboard 的关系

DSH 装了 `dsh-video-storyboard`（profile bundle），但它在预设作用域里不一定可见。
我们在 preset 里去掉了重复声明，避免冲突。

- 如果原生 `video_storyboard` 可用：它能直接把图片交给模型，效果更好
- 如果不可用：`bili_frames` 的"视觉描述"是保底方案，文本模型也能用

## 人格提示

`prompts/live.md` 里加了一段：

```
看视频先看信息与字幕；没有字幕或画面是重点，就切帧看画面，不要只凭标题猜。
评论区先看高赞和楼中楼回复。看到有意思的就记一句，别整理成报告。
```

## 已知限制

- 评论只能看到 top replies，不能完整展开楼中楼
- 切帧默认只扫前 4 分钟、240p（长视频要分段传 `from`/`to`）
- 视觉描述依赖本地视觉模型，冷启动会慢（首次可能几十秒）
- 没有接"发评论"能力（外部 MCP 有，但故意不暴露）
