## 2. 本轮落地（按可验证性）

### 2.1 后台 lab（`tools/lab*.mjs`）
- 起第二个独立 DSH Web 实例（`dsh --profile web --patch <runDir>/lab.patch.yml --no-open`），不碰 desktop；每 run 独立端口/stateDir/日志。
- `up / down / status / say / scene / script / export`；observer 把 `session/event`、ICL `session-events.jsonl`、time/focus/mc-link 状态合成人可读 `transcript.md`。
- 模型**显式 selectModel**（绝不继承 profile 默认）；`--model local` 走根锁 `.state/locks/llama.lock`。
- 证据：`.state/lab/<run>/`（transcript/events/context/state/rounds.jsonl）。

### 2.2 前缀缓存（`docs/CACHE-MODEL.md`、`tools/cache-probe.mjs`、`tools/cache-log.mjs`）
- 机制：NInfer/KVMem 按系统提示词指纹保留会话，**系统提示词任一字节变化 = 整条前缀作废**；DSH 对 ninfer 走 replace 首 system 节点。
- 修复（方案 B）：`icl:core` 只装 order<800 的静态段（persona 20 + sim 25）；order≥800 的动态事实合成一个 `systemPrompt.context('icl:facts')`，走 runtime-context 快照（只追加）。
- A/B（同代码、同场景、34 工具、gap 65s ×6）：system replace 6/6 → **0 replace**；prefill 59547→**9421**（-84%）；hit 41.5%→**91.2%**；TTFT 5.01–6.09s→**0.42–0.58s**；turnMs 6.6–11.6→1.6–1.9s（实测轮间隔 bf2≈72s / af2≈67s）。方案 A（动态段挪系统尾部）实测无收益。
- 已知：facts 快照只 append → 长会话线性累积（每变一次 ~458 字符；MC 多步 turn 会按步累积），见 §5 待办。

### 2.3 MC（`packages/mc-body`、`packages/plugins/mc-link`、`docs/MC-*.md`）
