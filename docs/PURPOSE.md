# 心里惦记的事（P2 最小版，2026-11-11）

## 来源

不新增 purpose 存储；直接用 note 插件已有的 open 项：

- `memo`：她给自己留的待办；
- `question`：dream 从不确定里提出来的待查；
- 以后可加 `promise`。

## 修复

- `memos` 默认返回**全部 open**，不再只看今天；`all` 保留为兼容参数；
- 输出 `#id [kind · 日期] 正文`，和 `note_status` 的 open 计数同口径；
- 移除世界状态里的裸计数“还有 N 件事没了结”，避免“看到 5、查是空的”。

## 注入

`note` 插件用 Feature Contract 注册 `purpose` 段：

- 依赖 `memos` / `memo_commit` 已注册；
- 最多 3 条，按创建时间从旧到新，优先让长期未结的事浮出来；
- 明确写“这不是任务清单，不需要每轮都提”；
- 内容动态，放在 facts 层（order 879），不写静态 system。

## sim 与工具的分工

- **sim**：只写通用态度——这些是自己没放下的事，不是 KPI；可以主动想起，不替用户做决定；没进展不必反复说；
- **Feature Contract**：负责“什么时候出现、最多几条、怎么措辞”；
- **工具 description**：负责“怎么查、怎么收尾、id 怎么用”。

不在 sim 里抄工具参数表。

## 不做的

- 四驱动衰减；
- 每回合 mood judge；
- 自动判断“她说没说出口”；
- 定时主动推送（心跳已由 time 负责）。
