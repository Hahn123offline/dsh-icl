# 诊断：为什么记忆块很薄

> 这一轮不跑，只回答"薄"的原因。样本来自 2026-11-02 的几次 5 分钟会话。

## 一、先说结论

薄不是单一原因，是**四个因素叠在一起**：

| # | 原因 | 现在的影响 | 性质 |
|---|---|---|---|
| 1 | wash 明确要求"一句话" | 笔记天生就是提纲 | 提示词 |
| 2 | 喂给 wash 的原文被截断（每行 240 字，最多 200 行） | 细节在进模型之前就没了 | 实现 |
| 3 | 主会话只翻 2 条评论、不追楼 | 材料密度低 | 人格/驱动 |
| 4 | 人物笔记没有主体归属，people 阶段看不见 | 人物档案永远为空 | 实现（已定位） |

前两条是"有人在推着写短一点"的确切来源——**是我们推的**。

---

## 二、证据

### 1. wash 要求一句话

`packages/plugins/dream/src/index.mjs` 的 wash 提示词原文：

```
输出 JSON 数组：[{"kind":"event|person","text":"一句话","source_id":"1"}]
```

一个 5 分钟会话里，wash 产出 2 条、每条一句。块再基于这一句扩写，自然薄。

旧记忆块常常 100+ 字，是因为旧管线**先有完整原文、再写块**；我们现在是
"一句提纲 → 再扩写成块"，中间的细节已经丢了。

**已改**：现在要求"每条写两三句，把具体细节写进去，不要只给一句提纲"。

### 2. 原文在喂进去之前就被截断了

```js
rows.slice(0, 200)
.map(r => `[i] ${text.slice(0, 240)}`)
```

240 字对聊天够用，对**视频字幕、评论楼、长描述**远远不够。

**未改**（需要讨论）：放宽到多少？我倾向按"总预算"而不是"每行上限"控制，
比如总共 12000 字，单行最多 1200 字。

### 3. 她只翻 2 条评论

会话记录里她看评论的调用是 `num: 8`、`num: 20`，但**读完就换下一个视频**，
不会进楼（`bili_comments` 目前也**没有展开楼中楼**的能力）。

两个层面：

- **意愿**：人格里没有"深挖"的驱动
- **能力**：工具拿不到楼中楼

你提的那段人格构想（"喜欢彻底研究、疯狂翻楼、刷同类话题"）我认为**不算逼**，
因为它是**给角色的偏好**，不是给它的任务。而且这也符合"自提示"的设计——
她想知道什么，就自己去查。

### 4. 人物记忆：不是没信号，是没归属

people 阶段的分组逻辑：

```js
const subject = note.data?.subject ?? (note.data?.qq ? {...} : null)
if (!subject?.value) continue      // ← 没有主体就整条跳过
```

wash 写笔记时只写了 `{day, washed, origin}`，**没有 subject**。
所以那次她连看 5 个吴阿姨的视频，people 阶段一条都没看到。

**已改**：wash 现在会输出 `who`，写库时存成 `data.subject = {kind:'name', value}`。

---

## 三、颗粒度问题

你说"两个视频看起来像刷了一下，完全可以同块"。现在**一个 note 一个块**，
是因为 events 的提示词要求"合并同一件事"，但没有"同一段经历"的概念。

建议（未实施）：给 wash 的笔记加 `session` 标记（同一天同一批），events 优先
把同 session 的笔记合成一块，而不是按 note 逐条成块。

---

## 四、思维链

- 之前测试脚手架**关掉了思考**，所以没有思维链可看
- 模型客户端的 `chat()` 原来只取 `content`，`reasoning_content` 被丢掉

**已改**：新增 `chatDetailed()` 返回 `{text, reasoning}`；脚手架会把思考记进
原始层（`kind: 'think'`）；`config/marathon.json` 已开启思考。

这会直接增加原始层的自然语言量——正是你想要的"全部见闻"。

---

## 五、待讨论（下一轮开始前）

1. **原文截断策略**：按总预算而不是单行上限？
2. **块的粒度**：要不要引入 "session"（一次连刷）作为合并单位？
3. **人物触发**：靠 wash 的 `who` 归属即可，还是也需要"同一 UP 出现 ≥N 次"？
   我倾向只靠归属，不做机械阈值。
4. **好奇心**：人格里加"喜欢深挖"的偏好，还是加工具（楼中楼）让她能挖？
